# Rentaro Extension Repo

Extension index for Aniyomi / Anikku and forks. Built automatically from
[rentaroarvin/rentaro-extensions](https://github.com/rentaroarvin/rentaro-extensions).

## Add this repo

Paste this URL into your app under **Settings → Browse → Extension repos → Add**:

```
https://raw.githubusercontent.com/rentaroarvin/rentaro-repo/repo/index.min.json
```

## Contents

| Path | Purpose |
| --- | --- |
| `index.min.json` | Minified index the app fetches |
| `index.json` | Same data, pretty-printed |
| `repo.json` | Repo metadata |
| `apk/` | Signed extension APKs |
| `icon/` | Extension icons |

Do not edit this branch by hand. CI regenerates and force-syncs it on every
push to the source repo's `main` branch.
